# 라벨 기준

gt100 v2와 최종 프로젝트 학습 사진은 이 기준으로 라벨링하고 검수한다.
정한 날: 2026-11-10 (변성진)

## 기본
- 클래스는 person=0, bicycle=1 두 개만 쓴다.
- 사진 속 사람과 자전거는 빠짐없이 라벨링한다. 빠진 객체가 있으면 모델이 맞게 찾은 것을 틀렸다고 배우고, 평가 점수도 실제보다 낮게 나온다.
- 박스는 보이는 부분에 딱 맞게 그린다. 가려지거나 잘려서 안 보이는 부분까지 짐작해 늘리지 않는다.

## 사람 (person)
| 경우 | 라벨 | 기준 |
|---|---|---|
| 사진 가장자리에 몸이 잘린 사람 | 함 | 머리나 몸통이 보여 사람으로 알아볼 수 있으면 보이는 부분만 박스 |
| 다른 물체에 가려진 사람 | 함 | 위와 같음 |
| 아주 작은 사람 | 함 | 사람으로 알아볼 수 있으면 크기와 상관없이 라벨 |
| 유리창 너머 실제 사람 | 함 | 가게 안 사람처럼 유리 너머에 실제로 있는 사람 |
| 유리·거울에 비친 모습 | 안 함 | 반사상은 실제 사람이 아니다 |
| 포스터·광고·화면·조각상 속 사람 | 안 함 | 실제 사람이 아니다 |
| 자전거를 탄 사람 | 함 | 사람과 자전거를 따로 박스. 두 박스가 겹쳐도 된다 |

## 자전거 (bicycle)
| 경우 | 라벨 | 기준 |
|---|---|---|
| 바퀴 두 개 자전거 (타는 중, 끄는 중, 세워 둔 것) | 함 | 보이는 부분만 박스 |
| 여러 대가 붙어 세워진 자전거 | 함 | 한 대씩 따로. 구분이 안 되는 부분은 보이는 범위에서 최선으로 |
| 시클로·세발자전거·카고 바이크 | 안 함 | 바퀴 두 개 자전거만 bicycle이다. 타고 있는 사람은 person으로 라벨 |
| 오토바이·킥보드 | 안 함 | 다루지 않는 클래스 |

## 애매할 때
- 사람인지 자전거인지 알아볼 수 없으면 라벨하지 않는다.
- 새로 애매한 경우가 나오면 이 문서에 줄을 더하고, 이미 라벨링한 사진도 같은 기준으로 맞춘다.
