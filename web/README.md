# web — 후방 감지 모니터

담당: 뼈대 변성진, 이후 화면·서버 연결 최수창

Jetson이 보낸 감지 캡처와 기록을 보여 주는 웹 화면입니다. 감지·경고음·기록 DB·웹 서버가 모두 Jetson 한 대 안에서 돌고, 인터넷과 외부 서버는 필요 없습니다.

**화면은 두 가지입니다.**

| 주소 | 누구 | 내용 |
|---|---|---|
| `http://<Jetson IP>:8000/` | **운전자** | 차 내비 화면이나 휴대폰에서 보는 보조 화면. 영상 위, 경고 단계(삐/삐삐/삐삐삐)와 위험율 아래(후방주차 화면처럼). 항상 어둡게. 시연 녹화는 이 화면 |
| `http://<Jetson IP>:8000/admin` | **관리자·운영자** | 나중에 확인하는 화면. 기록표, 오경보 표시, 통계, 재학습 자료 내보내기. 위쪽 오른쪽에 화면 전환과 밝게/어둡게 버튼 |

관리자 화면 위쪽의 **매뉴얼** 버튼은 신입 관리자용 요약을 화면 오른쪽에 겹쳐 엽니다(다른 페이지로 가지 않고, `Esc`나 닫기로 닫음). 하는 일, 매일 점검, 재학습 순서, 하지 말 것을 담았고, 오경보 판단 기준은 기록표 옆 "무엇을 오경보로 표시하나요?"(`JudgeTable.tsx`)를 참고하라고 한 줄로 안내합니다(`src/components/ManualDrawer.tsx`, 근거는 `docs/false-alarm-retraining.md`).

두 화면 모두 같은 Jetson 서버가 주고 주소(경로)로만 나뉩니다. `/admin`을 못 여는 정적 서버(`python -m http.server`)에서는 `/?view=admin`을 씁니다. 옛 주소 `?view=drive`, `?view=demo`는 운전자 화면입니다. **로그인은 없습니다** — `/admin`은 숨긴 주소일 뿐 보호가 아니므로, 신뢰하는 네트워크에서만 엽니다.

경고음은 Jetson이 울리고, 이 웹은 소리 곁에서 돕는 **보조 화면**입니다. 차의 후방주차 화면·소리를 대신하지 않습니다(소리 음색을 구분하는 일은 아직 안 함).

## 환경

| | 버전 |
|---|---|
| Node | **20 이상** (개발·빌드는 v26.13.1에서 확인) |
| npm | 11.20.0 |
| React | 18.3.1 |
| Vite | 8.3.8 |
| TypeScript | 5.6.3 |

버전은 `package.json`에 범위 없이 고정했고, `package-lock.json`을 레포에 올립니다. **시연하는 PC에는 Node가 필요 없습니다** — 빌드한 `dist/`만 있으면 됩니다.

## 쓰는 법

```bash
cd web
npm ci            # package-lock.json 그대로 설치 (npm install 아님)
npm run dev       # 개발 서버 http://localhost:5173
npm run build     # 타입 검사 후 dist/ 생성
npm run typecheck # 타입만 검사
```

`npm run build`는 `tsc --noEmit`을 먼저 돌리므로 **타입 오류가 있으면 빌드가 실패합니다.**

### 발표용 시연

```bash
npm run build
```

나온 `dist/` 폴더를 통째로 옮겨 아무 정적 서버로 엽니다.

```bash
cd dist && python -m http.server 8123   # http://localhost:8123
```

`dist/index.html`을 파일로 바로 여는 것은 **안 됩니다.** 브라우저가 `file://`에서 ES 모듈을 막습니다. 반드시 서버로 여세요.

> 발표 전날 `dist/`를 압축해 드라이브에 백업해 둡니다. 빌드가 깨져도 그걸로 바로 시연합니다.

## 서버와 주고받는 것

서버는 `server/`(`python -m server`)입니다. 화면은 `GET /api/detections`를 먼저 시도하고, 실패하면 `demoData.ts`로 넘어갑니다. 상단에 **"Jetson 연결됨"** / **"서버 없음 · 예시 기록"** 으로 구분해 표시합니다.

```jsonc
// GET /api/detections  →  Detection[]
{
  "id": "CAP-118",
  "shot": "shots/shot1.jpg",   // 캡처 이미지 경로
  "at": "21:48:12",
  "person": 4,                  // 사람 박스 수
  "bicycle": 1,                 // 자전거 박스 수
  "top": 0.93,                  // 가장 높은 신뢰도
  "ms": 24,                     // 추론 시간
  "level": 2,                   // 경고 단계 0~3
  "dist": 3.1,                  // 추정 거리(m)
  "false_alarm": false          // 오경보 표시(서버가 보관, 화면을 열 때 불러옴)
}
```

- `POST /api/detections` — Jetson이 캡처와 감지 정보를 올립니다.
- `PATCH /api/detections/<id>` — 오경보 표시를 서버에 남깁니다. 서버가 없으면 화면 안에서만 바뀝니다.

### 경고 단계

주차 센서 방식입니다. 거리는 사람 발 위치(박스 아래 끝)로 추정하며, 카메라 높이 70cm 고정과 평탄한 바닥을 가정한 근사치입니다.

| 단계 | 거리 | 소리 |
|---|---|---|
| 1 | 약 5.5m | 삐 |
| 2 | 약 3m | 삐삐 |
| 3 | 약 2m | 삐삐삐 |

기준값은 코드에 박지 않고 **`거리기준` 클립에서 2m 발 위치를 재서 정합니다.**

발끝이 화면 아래로 잘리면 박스 아래 끝이 화면 끝이 되어 거리값이 실제보다 가깝게 나옵니다. 그 경우 숫자 대신 **"2m 이내, 3단계"**로 처리할 예정입니다.

## 관리자 화면 구성 (최신)
- **실시간 화면 + 위험율·감지율 막대**: runner가 그린 박스·거리선 화면(`/api/preview`)과, 가장 가까운 사람·자전거의 거리(위험율)·신뢰도(감지율) 막대, 경고 단계(삐/삐삐/삐삐삐). 0.25초마다 `/api/status`를 읽는다. 운전자 화면(`/`)은 이 실시간 화면과 경고 단계, 위험율만 크게 보여 준다.
- **기록 저장 상태**: 상단에 "기록 저장(SQLite) N건 · 오경보 M건 보호". 기록은 이 기기의 SQLite 파일에 저장되고 인터넷이 필요 없다(`/api/health`).
- **감지 기록 표**: 화면 높이에 맞춰 한 쪽 건수를 자동으로 정해 페이지로 나눈다(관리자 화면이 스크롤 없이 한 화면에 들어오게. 720px 높이에서 4건, 1080px에서 12건). 너무 좁거나 낮은 화면(너비 880px 이하, 높이 620px 미만)에서는 칸을 쌓고 페이지를 스크롤한다. "오경보로 표시"를 누르면 서버 DB에 저장되고 통계의 **오경보율**(표시 수 ÷ 경보 수)에 반영된다. 표시한 기록은 자동 삭제되지 않는다.
- **오경보 내보내기(zip)**: 표시한 기록의 원본 사진 + 빈 라벨 + 목록을 받는다(재학습 때 "이건 사람이 아니다"를 가르치는 배경 자료). 사람이 있는 기록은 표시하지 않는다.
- 외부 글꼴(Google Fonts)을 불러오지 않는다. 인터넷이 없는 Jetson 네트워크에서도 바로 뜬다. 차트 라이브러리는 쓰지 않는다(막대는 CSS).

- 무엇을 오경보로 표시하는지(화면의 "무엇을 오경보로 표시하나요?")와 재학습 절차는 `docs/false-alarm-retraining.md`를 본다.
